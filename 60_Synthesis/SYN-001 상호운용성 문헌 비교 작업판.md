## 문헌 쌍 비교 가능성

| 문헌 A | 문헌 B | 시스템 대응 | 시나리오 대응 | 지표·기준 대응 | 판정 | 허용되는 비교 | 비교 금지 또는 주의 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  | direct / conditional / narrative / not_comparable |  |  |

판정 의미:

- `direct`: 정의와 조건이 같거나 변환 가능해 정량 직접 비교 가능
- `conditional`: 차이를 명시하면 제한적 정량 비교 가능
- `narrative`: 방법·실패 모드·정보 경계의 서술 비교만 가능
- `not_comparable`: 같은 수치나 우열 결론에 사용하지 않음

## 잠정 종합

원문 검토 전에는 결론을 작성하지 않는다. 작성 시 각 문장 끝에 근거 카드 링크를 붙이고 다음을 구분한다.

1. 여러 문헌에서 일치하는 결과
2. 조건에 따라 달라지는 결과
3. 상충하는 결과
4. 자료가 비공개이거나 보고되지 않아 확인할 수 없는 항목
5. 검색 범위에서 찾지 못한 항목
