# v0.1 실행 백로그

## 운영 규칙

우선순위는 P0 차단, P1 핵심, P2 개선 순이다. `완료`는 완료 기준과 증빙 위치가 모두 채워진 상태다. 이 문서의 체크박스는 계획이며 현재 완료를 뜻하지 않는다.

| ID | 우선순위 | 작업 | 의존성 | 예상 | 완료 기준 | 상태 |
|---|---|---|---|---:|---|---|
| B-001 | P0 | RQ-001 주축과 범위 결정 | 없음 | 45분 | 제어/보호/시험방법 중 주축 1개, 인접 범위, 제외 범위가 기록됨 | 대기 |
| B-002 | P0 | 라이선스 결정 | 없음 | 30분 | 선택 이유와 적용 범위가 기록되고 `LICENSE` 반영 작업이 승인됨 | 결정 대기 |
| B-003 | P0 | 공개 대상 파일 인벤토리 확정 | 없음 | 45분 | 추적/제외/조건부 공개가 파일·패턴별로 구분됨 | 대기 |
| B-004 | P0 | 민감정보·저작권 점검 | B-003 | 45분 | 절대경로·계정·개인정보·원문 파일·권리 미확인 첨부가 0건 | 대기 |
| B-005 | P0 | 상태·성과 수치 점검 | B-001 | 30분 | 실제 0인 성과가 계획값과 구분되고 `reviewed`/`checked` 오표시가 0건 | 대기 |

| B-010 | P1 | Git dry run과 첫 커밋 목록 검토 | B-004~B-008 | 30분 | `git status` 예상 목록에 제외 대상이 없고 실제 원격 작업은 하지 않음 | 대기 |
| B-011 | P1 | v0.1 릴리스 노트 초안 | B-005 | 30분 | 포함 문서, 실제 연구 성과 0, 알려진 한계, 다음 단계가 명시됨 | 대기 |
| B-012 | P1 | 1주차 검색 프로토콜 고정 | B-001 | 45분 | 검색원·검색식·기간·선별 기준·기록 위치가 한 묶음으로 정의됨 | 대기 |
| B-013 | P1 | 파일럿 검색 1회 실행 | B-012 | 45분 | 검색 일시·식·필터·결과 수·후보가 실행 기록에 남음 | 대기 |

| B-018 | P2 | 자동 링크 검사 스크립트 검토 | B-006 이후 | 60분 | CI 도입 여부와 지원 범위가 기록됨 | 대기 |

## 공개 직전 중단 조건

다음 중 하나라도 해당하면 공개 저장소 생성·업로드를 중단한다.

- 라이선스 미정
- 공개 대상에 권리 미확인 첨부자료 또는 원문 파일 포함
- 개인 경로·계정·비공개 메모 노출
- 연구 성과 수치나 상태가 실제 확인 범위보다 높게 표시됨
- 대표 문서 링크가 깨짐
