# 1-2주차 실행 계획

이 계획은 개인 운영자 1인, 주 4~6시간을 기준으로 한다. 2026-09-09 RQ-001의 인터페이스·시험방법 주축을 확정하고 공식 보고서 4건을 선별했다. 2026-09-10 D1.3 공식 보고서 한 건을 지정 범위에서 정독해 근거 2건과 SYN-001 첫 행을 만들었다. 공식 보고서는 논문 정독 목표와 분리한다.

## 1주차 — 범위와 검색 프로토콜 고정

### 시간 배분

| 순서 | 작업 | 시간 | 산출물 |
|---:|---|---:|---|
| 1 | RQ-001 주축 선택과 질문문 수정 | 45분 | 대상·현상·비교·지표·제외 범위가 있는 질문 |
| 2 | 포함·제외·보류 기준 시험 적용 | 45분 | 예시 후보 5건에 대한 일관된 판정 메모 |
| 3 | 검색원과 검색식 확정 | 45분 | 검색원별 실행 가능한 식과 기간 |
| 4 | 공개 준비 P0 점검 | 60분 | 라이선스 제외 나머지 차단 항목 목록 |
| 5 | 파일럿 검색 1회와 후보 등록 | 60분 | 실행 기록 1건과 후보 목록 |
| 6 | 회고·다음 작업 고정 | 15분 | 다음 주 첫 정독 후보 1~2건 |

### 완료 기준

- [x] 질문이 한 문장으로 재현되고, 주축 1개와 인접 범위가 구분됨

- [x] 검색 실행 기록에 검색원, 정확한 식, 기간, 실행일과 결과 수 미제공 제한이 기록됨
- [x] 후보마다 문서 유형·접근 수준·중복 가능성·판정 이유가 있음
- [x] 선택한 주축과 이유를 기록한 뒤 RQ-001을 `active`로 전환함

### 초과 작업 금지선

1주차에는 후보 수를 늘리기 위해 검색원을 무제한 추가하지 않는다. 원문을 읽지 않은 후보는 `reviewed`로 표시하지 않는다. 공개 저장소에는 외부 원문 파일·개인 메모를 올리지 않는다.

| 2 | 접근 가능한 핵심 논문 1편 정독 | 120~180분 | paper 노트 1개; 공식 보고서와 별도 집계 |

## 남은 2주차 우선순위와 완료 기준

1. **학술논문 후보 3~5건 확보** — 제목·초록 선별과 공식 발행처/DOI를 기록하고, 포함·제외·보류 예시를 최소 한 건씩 남긴다.
2. **학술논문 1편 정독** — 원문 접근 범위, 시스템·방법·시나리오·결과·한계와 페이지 위치를 기록한다.
3. **D1.1 대조** — 모델 유형·신호·공급 경계를 D1.3 첫 행과 같은 필드로 입력한다. 이 작업은 보고서 간 서술 비교이며 논문 실적과 분리한다.
4. **첫 쌍 비교 판정** — D1.3↔D1.1의 대응 범위를 `narrative` 또는 `conditional`로 판정하고 이유를 남긴다.
