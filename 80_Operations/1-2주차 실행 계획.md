# 1-2주차 실행 계획

이 계획은 개인 운영자 1인, 주 4~6시간을 기준으로 한다. RQ-001이 선택되지 않으면 같은 절차를 확정된 질문에 적용한다. 체크박스는 모두 미수행 계획이다.

## 1주차 — 범위와 검색 프로토콜 고정

### 시간 배분

| 순서 | 작업 | 시간 | 산출물 |
|---:|---|---:|---|
| 1 | RQ-001 주축 선택과 질문문 수정 | 45분 | 대상·현상·비교·지표·제외 범위가 있는 질문 |
| 2 | 포함·제외·보류 기준 시험 적용 | 45분 | 예시 후보 5건에 대한 일관된 판정 메모 |
| 3 | 검색원과 검색식 확정 | 45분 | 검색원별 실행 가능한 식과 기간 |
| 4 | 공개 준비 P0 점검 | 60분 | 라이선스 제외 나머지 차단 항목 목록 |
| 5 | 파일럿 검색 1회와 후보 등록 | 60분 | 실행 기록 1건과 후보 목록 |
| 6 | 회고·다음 작업 고정 | 15분 | 다음 주 첫 정독 후보 1~2건 |

### 완료 기준

- [ ] 질문이 한 문장으로 재현되고, 주축 1개와 인접 범위가 구분됨
- [ ] 포함·제외·보류 기준이 각각 최소 한 사례에 적용됨
- [ ] 검색 실행 기록에 검색원, 정확한 식, 필드, 기간, 실행일, 결과 수가 있음
- [ ] 후보마다 문서 유형·접근 수준·중복 가능성·판정 이유가 있음
- [ ] RQ-001이 사용자 선택 없이 `active`로 바뀌지 않음

### 초과 작업 금지선

1주차에는 후보 수를 늘리기 위해 검색원을 무제한 추가하지 않는다. 라이선스가 미정인 동안 공개 저장소 업로드를 하지 않는다. 원문을 읽지 않은 후보는 `reviewed`로 표시하지 않는다.

## 2주차 — 첫 추적 가능한 연구 묶음

### 시간 배분

| 순서 | 작업 | 시간 | 산출물 |
|---:|---|---:|---|
| 1 | 중복·버전 관계 확인과 후보 4건 선별 | 45~60분 | 등록부의 결정과 사유 |
| 2 | 접근 가능한 핵심 논문 1편 정독 | 120~180분 | paper 노트 1개 |
| 3 | 근거 추출·원문 대조 | 45~60분 | 핵심 근거가 있을 때 카드 1~2개 |
| 4 | SYN-001 비교표 첫 입력 | 20~30분 | 문헌 1행과 비교 가능성 판정 |
| 5 | 상태·수량·링크 자체검토 | 20분 | 오류 수정과 운영 기록 |

### 완료 기준

- [ ] 고유 문헌 후보 4건이 포함 또는 보류로 선별되고 중복 버전은 한 연구로 묶임
- [ ] 논문 1편의 실제 원문 접근 범위가 기록됨
- [ ] 문제·시스템·방법·시나리오·결과·한계가 정독 노트에 있음
- [ ] 수치 근거가 있다면 단위·기준·원문 위치·조건이 대조됨
- [ ] 핵심 근거가 없다면 카드 수를 채우지 않고 사유가 기록됨
- [ ] 질문 → 논문 → 근거 → 종합 작업판의 링크가 한 방향 이상 연결됨
- [ ] 실제 누적 수치가 계획 목표와 별도로 대시보드에 기록됨

## 2주 종료 판정

| 판정 | 조건 | 다음 행동 |
|---|---|---|
| 계속 | 공통 비교 항목을 1편 이상에서 채울 수 있음 | 같은 주축의 문헌 2~3편을 추가 정독 |
| 범위 축소 | 인터페이스·시나리오·지표 중 절반 이상이 지속적으로 미확인 | 제어/보호/시험방법 중 더 좁은 주축으로 수정 |
| 자료원 전환 | 핵심 원문 접근 불가가 비교를 막음 | 공개 보고서·저자 공개본·기관 자료를 탐색하고 결론은 유보 |
| 질문 교체 검토 | 포함 후보가 4건 미만이거나 서로 비교 불가 | 파일럿 목적에 맞는 인접 질문을 제안 상태로 작성 |
