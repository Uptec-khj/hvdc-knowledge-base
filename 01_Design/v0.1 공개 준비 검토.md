# v0.1 공개 준비 검토

## 검토 결론

현재 설계는 `질문 → 문헌 → 근거 → 종합 → 후속 질문`의 연결 원칙, 공개·비공개 자료 분리, 문헌 상태 구분이 잘 맞물린다. 다만 v0.1 공개와 12주 연구 시작의 경계, 수량 집계 단위, RQ-001의 선별 기준, 라이선스 미정 상태에서의 공개 게이트가 불명확하다. 아래 수정은 v0.1을 **연구 운영체계 공개 준비판**으로 한정하고 실제 연구 성과 0건과 혼동하지 않게 한다.

## 누락된 운영 규칙

### 수량 집계

- `선별 1건`: 포함 결정이 완료된 **고유 연구 또는 공식 기술 문서** 한 건. 같은 연구의 preprint와 최종판은 한 건이다.
- `논문 정독 1편`: journal, conference, preprint 중 원문을 읽고 정독 완료 기준을 충족한 고유 연구 한 편.
- `근거 1개`: 단일 핵심 주장과 원문 위치·조건·한계를 갖춘 카드 한 개. `checked`만 완료 수량으로 집계한다.
- `종합 1개`: 둘 이상의 고유 연구를 비교하고 결론별 근거 링크를 갖춘 노트 한 개. `reviewed`만 완료 수량으로 집계한다.
- 프로젝트 소개, 보도자료, 단순 서지 페이지는 맥락 자료이며 논문 정독 수량에 포함하지 않는다.

### 상태 변경 권한

개인 운영자 1인이 작성자와 검토자 역할을 겸한다. 따라서 상태 변경은 별도 사람의 승인 대신 체크리스트 충족과 변경 기록으로 통제한다. `reviewed`, `checked` 전환 커밋에는 충족한 기준과 확인 범위를 적는다.

### 공개 릴리스 표기

모든 릴리스 설명에는 다음을 함께 적는다.

1. 연구 범위와 검색 종료일
2. 선별·정독·근거·종합의 실제 수치
3. 원문 접근 범위와 미확인 항목
4. 라이선스 적용 범위와 외부 자료 제외 고지
5. 계획·제안과 검토 완료 결과의 구분

### 필수 P0

- [ ] 문서·템플릿 라이선스가 결정되고 공식 전문이 `LICENSE`에 추가됨
- [ ] README·CONTRIBUTING의 라이선스 문구가 `LICENSE`와 일치함
- [ ] 공개 파일에 원문 PDF·표준 파일·개인 메모·로컬 절대경로·계정 정보가 없음

- [ ] 저장소 소유자와 이름이 확정됨
