# 12주 구축 로드맵

## v0.1 공개 준비와 연구 시작의 구분

v0.1은 설계·템플릿·운영 기준을 공개할 수 있는 준비판이다. 연구 1주차 전 또는 1주차 후에 공개할 수 있지만, [공개 전 점검표](../PUBLICATION_CHECKLIST.md)의 P0 항목을 모두 통과해야 한다. 라이선스가 미정이면 공개 후보 패키지와 dry run까지만 수행하고 저장소 공개·업로드·릴리스는 보류한다.

RQ-001은 사용자 확정 전까지 `proposed`를 유지한다. v0.1에 포함할 때는 파일럿 제안이라는 표시와 실제 연구 성과가 0이라는 설명을 유지한다.

## 일정과 집계 가정

시작일을 정한 뒤 1주차부터 적용한다. 주 4~6시간, 한 번에 정독하는 논문은 최대 두 편이다. 12주 목표는 고유 문헌 선별 24건, 논문 정독 12편, `checked` 근거 24개, `reviewed` 종합 노트 3개, 후속 질문 3개다.

- 고유 문헌은 같은 연구의 사전공개판·최종판·정정판을 한 묶음으로 센다.
- ‘논문 정독’은 journal, conference, preprint 원문을 읽고 정독 완료 기준을 충족한 경우만 센다.
- 공식 프로젝트 페이지·서지 페이지만 확인한 `source`는 논문 정독 수량에 포함하지 않는다.
- 근거는 수량을 맞추기 위해 분할하지 않으며 `checked`만 완료 수량으로 센다.
- 계획값과 실제값은 대시보드와 운영 기록에서 별도 열로 관리한다.

## 12주 일정

| 주차 | 핵심 작업 | 누적 제안 목표 | 완료 조건 |
|---|---|---|---|
| 1 | 질문 주축·범위 확정, 검색 프로토콜 1회 실행 | 활성 질문 1개 또는 파일럿 보류 결정, 후보 등록 | 대상·현상·비교·지표·제외 범위와 정확한 검색 실행 기록이 있음 |
| 2 | 중복 제거·선별·첫 정독 | 선별 4건, 정독 1편, 근거 최대 2개 | 원문 접근 범위가 기록된 질문→논문→근거→비교 작업판 한 묶음 |
| 3 | 검색 보완·정독 | 선별 8건, 정독 3편 | 포함·제외·보류 이유와 버전 관계 기록 |
| 4 | 최초 비교·입력 항목 조정 | 선별 12건, 정독 4편, 근거 8개, 종합 1개 | G1 통과 |
| 5 | 방법별 문헌 묶음 구성 | 선별 15건, 정독 5편, 근거 10개 | 선택한 주축의 비교 항목이 통일됨 |
| 6 | 반례·다른 조건 탐색 | 선별 18건, 정독 7편, 근거 14개 | 상충 결과나 적용 한계 기록 |
| 7 | 공개 자료의 재현 가능성 평가 | 선별 21건, 정독 8편, 근거 16개 | 필요 파일·도구·누락 정보·예상 시간 표 작성 |
| 8 | 두 번째 종합·동향 영향 검토 | 선별 24건, 정독 9편, 근거 18개, 종합 2개 | G2 통과 |
| 9 | 핵심 불확실성 보완 | 정독 10편, 근거 20개 | 우선 질문의 미확인 항목 감소 또는 유보 이유 명시 |
| 10 | 후속 질문 후보 작성 | 정독 11편, 근거 22개, 후속 질문 3개 | 질문별 근거·필요 데이터·실행성 명시 |
| 11 | 최종 정독·종합 | 정독 12편, 근거 24개, 종합 3개 | 주장별 근거와 비교 한계 확인 |
| 12 | 실제값 대조·복원·다음 분기 계획 | 최종 대시보드·운영 회고 | G3 통과 또는 미달 사유·이월 계획 기록 |

수량은 누적 제안 목표이며 성과를 미리 의미하지 않는다. 2주차의 ‘근거 최대 2개’는 논문에 재사용할 핵심 근거가 있을 때만 적용한다. 3·6주차는 정독 부담이 높으므로 짧은 논문을 배치하거나 다음 주로 나눈다.

## 1~2주차 상세 실행

세부 시간 배분과 중단 기준은 [1-2주차 실행 계획](../80_Operations/1-2%EC%A3%BC%EC%B0%A8%20%EC%8B%A4%ED%96%89%20%EA%B3%84%ED%9A%8D.md)을 따른다.

### 1주차 필수 결과

- [ ] RQ-001의 주축을 제어/보호/인터페이스·시험방법 중 하나로 결정하거나 파일럿을 보류함
- [ ] 포함·제외·보류 기준을 예시 후보에 시험 적용함
- [ ] 검색원·정확한 검색식·기간·실행일·결과 수를 기록함
- [ ] 공개 준비 차단 항목을 확인하되 라이선스 결정 전 업로드하지 않음

### 2주차 필수 결과

- [ ] 고유 문헌 4건의 선별 결정과 버전 관계를 기록함
- [ ] 원문 접근 가능한 논문 1편을 정독 기준에 따라 검토함
- [ ] 근거가 있을 때만 카드 1~2개를 만들고 원문 위치·조건·한계를 대조함
- [ ] SYN-001의 첫 문헌 행과 비교 가능성 판정을 채움

## 단계별 통과 기준

### G1 — 4주차, 운영 가능한 최소 창고

- [ ] 고유 논문 4편의 원문을 정독 완료하고 질문과 연결했다.
- [ ] 근거 카드 8개의 원문 위치·조건을 대조해 `checked`로 표시했다.
- [ ] 최소 두 고유 연구를 비교한 종합 노트 한 개가 `reviewed`다.
- [ ] 같은 연구의 중복 버전이 수량에 중복 포함되지 않았다.
- [ ] 새 노트 생성·분류·링크 연결을 도움 없이 수행한다.

통과하지 못하면 새 분야를 추가하지 않고 입력 항목을 줄이거나 질문을 좁힌다.

### G2 — 8주차, 비교가 가능한 연구 기반

- [ ] 동일 기준으로 비교 가능한 연구와 비교 불가 연구가 구분된다.
- [ ] 상충하는 주장 또는 적용 한계가 별도 기록되어 있다.
- [ ] 실험 재현의 필요 파일·도구·누락 정보·예상 시간을 파악했다.
- [ ] 기술 발표의 주장과 검증 결과를 구분한 동향 기록이 있다.

모델·원문 접근이 막히면 재현 실행은 미루고 공개 데이터 확보 계획과 방법 비교로 대체한다.

### G3 — 12주차, 반복 운영과 재사용

- [ ] [HVDC 연구 대시보드](../00_Home/HVDC%20%EC%97%B0%EA%B5%AC%20%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C.md)의 목표와 실제 수치를 대조했다.
- [ ] 중요한 종합 결론에서 원문 위치까지 역추적했다.
- [ ] 개인 백업에서 대표 파일을 복원했다.
- [ ] 공개 저장소의 clean clone 또는 새 공개 후보 사본에서 대표 탐색 경로를 확인했다.
- [ ] 다음 분기의 질문 세 개에 우선순위를 매겼다.

## 이후 3~6개월

1. **4개월차:** 핵심 질문 한 개의 재현 실험 또는 공개 벤치마크 분석. 성공 기준·환경·입력·실패 기록을 남긴다.
2. **5개월차:** 근거가 축적된 두 번째 분야를 확장하고 첫 질문과 연결한다.
3. **6개월차:** 검토 범위·검색 이력·한계를 명시한 기술 리뷰 또는 연구 제안서를 작성한다.

## 일정이 밀릴 때

주 2시간 이하이면 질문 하나를 유지하고 정독·근거·종합 목표를 절반으로 줄이거나 기간을 연장한다. 2주 연속 적체가 늘면 수집을 일시 중지하고 현재 논문을 마친다. 목표 변경은 [연구 운영 기록](../80_Operations/%EC%97%B0%EA%B5%AC%20%EC%9A%B4%EC%98%81%20%EA%B8%B0%EB%A1%9D.md)에 이유·기존 목표·새 목표·적용일을 남긴다.
