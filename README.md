## 현재 상태

v0.1은 연구 운영체계와 파일럿 질문의 공개판입니다. 실제 연구 성과는 **고유 문헌 선별 4건, 논문 정독 0편, checked 근거 2개, reviewed 종합 0개**입니다. 별도 보조 지표로 공식 보고서 D1.3 한 건을 지정 범위에서 정독했습니다. 수량 목표는 계획이며 완료 실적이 아닙니다.

첫 파일럿인 [RQ-001 다중 벤더 HVDC 상호운용성 검증](20_Questions/RQ-001%20다중%20벤더%20HVDC%20상호운용성%20검증.md)은 **인터페이스·시험방법**을 주축으로 `active` 상태입니다. InterOPERA 공식 보고서 4건을 선별했고, [D1.3 검토 노트](30_Literature/P-2026-003%20InterOPERA%20D1.3%20다중%20벤더%20EMT%20상호작용%20연구%20절차.md)에서 단독 시험/시스템 상호작용 연구의 경계와 모델 공유 조건을 원문 위치까지 대조했습니다. 공식 보고서 정독은 12주 목표의 논문 정독 수량에 합산하지 않습니다.

## 공개 범위

직접 작성한 설계·요약·근거·비교·템플릿을 공개합니다. 논문·표준 원문 파일, 제3자 그림, 개인 메모와 비공개 실험자료는 포함하지 않습니다. 외부 자료는 DOI와 공식 발행처 링크를 우선 기록합니다.
